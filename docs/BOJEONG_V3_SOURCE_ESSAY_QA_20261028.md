# 사업성 보정계수 V3 — 출처 검증, 발표 QA, 에세이 준비
검토일: 2026-10-28 (KST) · 대상: `presentation-v3/index.html` (본문 29장 + 참고 6장)

## 1. 에세이용 핵심 화두
**“허용용적률의 계획 인센티브는 정비사업의 경제성·공공성·실제 추진 성과를 얼마나 개선하는가?”**

중심 주장 초안: 서울시 사업성 보정계수(K)는 저사업성 지역의 허용용적률 인센티브를 확대해 계획상 분양 가능량을 보완한다. 하지만 보정된 용적률과 실제 일반분양 면적, 사업수지, 조합원 분담금, 착공까지의 소요기간은 각각 다른 지표다. 도시계획의 성과는 **K 미적용 기준안과 적용안의 비교 가능성**, **공공공간·임대주택 등 공공성의 변화**, **최종 사업비·분양수입·조합원 부담**을 함께 검증할 때 더 정확하게 판단할 수 있다.

### 연구·논증 질문
1. **형평성:** 지가가 낮은 지역에 더 많은 허용 인센티브를 주는 방식은 지역 간 사업성 격차를 어느 정도 보완하는가?
2. **계획의 실현성:** K가 제공한 추가 허용용적률은 실제 분양 가능한 주택, 공공임대, 보행공간, 공원에 어떻게 배분되는가?
3. **실무 수지:** 추가 매출과 추가 사업비를 함께 고려하면 종전자산 비례율과 개별 부담이 어떻게 달라지는가?
4. **정책 평가:** 심의 통과 수와 계획상 공급물량을 넘어, 인허가·착공·정산 결과를 어떻게 검증할 수 있는가?

### 에세이 구성안(작성은 추후)
- 서론: 공사비 압박과 지역별 분양수입 차이 — 지가 차이를 설계 인센티브에 반영한다는 정책적 선택.
- 제도적 배경: 도시정비법 → 2030 서울시 기본계획 → 2024 사업성 개선 세부기준 → 개별 정비계획 고시.
- 작동 원리: 기준·허용(계획 인센티브)·상한(공공기여)·법적상한의 구분; 재개발·재건축 K 산식.
- 사례: 석관4구역 실제 인센티브 20%p, K 1.86, 허용 241.5%, 전체 추정 비례율 107.28%; 서울시 발표 계획상 분양가능 +86세대(다른 계획 변경 포함).
- 현황: 2026.02 심의 통과 57곳, 강북30·서남24·기타3, 구역당 평균 +47세대 *계획상 추정*.
- 비판: 용적률의 실현가능량, 공공성 배분, 최종 사업수지 및 착공 촉진의 인과관계 자료 부족.
- 대안: K=1.0 대조 기준안과 적용안의 **동일 조건 비교표**, 공공성 지표 동시 공개, 사업 ID 기반 후속 모니터링.
- 결론: 계획 인센티브의 성과와 실제 사업의 성과를 분리해 평가.

### 예상 반론과 답변 자료
- “용적률을 더 주면 공공기여·임대를 깎는 것 아닌가?” → 허용 인센티브(계획 조건)와 상한(공공기여)은 구분. 실제 공공임대·공공시설 변동은 별도 평가.
- “K 때문에 실제 분담금이 얼마 줄었나?” → 석관4구역 고시의 107.28%는 **변경 후 전체 추정 비례율**이며 K 단독 순증분이 아님. 2024 서울시 +86세대·약 7,700만 원 경감도 다른 계획 변경과 결합된 **계획상 추정**.
- “사업성을 검토하는 것은 기존 실무인데 새 제안이 뭔가?” → 동일 부지·계획요소·분양단가·단위사업비·기간을 고정한 *K=1.0 기준안 vs 실제 K안* 공통 비교틀을 **공개**하는 것.
- “57곳이 다 지도에 없는데?” → 57은 **공식 심의 통과 집계**, 별도 20곳은 개별 위치·자료 탐색용. 공식 57곳 전체와 20곳의 포함 여부 일대일 대조는 미완료.

## 3. 수치·방법 주의사항
- 공사비지수 138.74는 **한국건설산업연구원 2026.10 발표의 2026.08 수치**. 2021–2025 연평균은 다른 공시 인용 자료에서 취합되었으므로 같은 축을 썼다고 곧 직접 계약 공사비의 증가율이 되는 것은 아니다. 관측자료·산정 기준 확인 필요.
- 2025 재개발 공시지가 **6,302,982원/㎡** 공고는 2026년 3월 등록. 석관4구역 K 1.86은 **2023년 지가 5,861,129 / 3,167,883 = 1.85017 → 올림 1.86**.
- 석관4구역 허용 인센티브: 공공보행통로 3.5 + BF 5 + 돌봄 4.1 + 고령서비스 2.4 + 층간소음 5 = **20.0%p**. 기준 204.3 + 20×1.86 = **241.5%**, K=1 단순 대비 +17.2%p.
- 석관4구역 공식 추정수지(단위 천원): 수입 **1,168,692,802**, 지출 **793,493,701**, 종전자산 **349,722,321**. (수입−지출)/종전자산×100 = **107.2849%**, 고시의 **107.28%**와 부합.
- 공식 민감도: 기준 **107.28%**, 정비사업비 +5% **95.94%**, 일반분양가 −5% **98.02%**, 양쪽 **86.67%**. 일반분양가 −5%는 총수입 전체 −5%라는 의미가 아니다(고시 일반분양 수입 648,358,675천원).
- α·β는 적용조건이 있는 행정적 보정. **β 110㎡ 이상에서 가산 제외**, 단순 세대수 문턱이 아님. 가상 동일 연면적 30,000㎡/250=120㎡(β=0), /350=85.71㎡(보간 후 β≈0.19).
- 57곳은 2026.02 공식 심의 집계. 조사 지도 20곳은 별도로 수집한 데이터이며 공식 명부와 일대일 대조하지 않았으므로 전체 통계의 추정 표본으로 사용하지 않는다.
